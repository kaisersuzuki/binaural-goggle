## Build

**ESP32-S3** (U3 is an ESP32-S3-WROOM-1-N8R8, not a classic ESP32):
```bash
cd firmware/esp32
pio run -e goggle                 # build
pio run -e goggle -t upload       # first flash via USB-UART on H3
pio run -e goggle_ota -t upload   # later, over WiFi (192.168.4.1)
```
There is no serial monitor: the only wired UART pads carry the dsPIC link. Debug goes to `http://192.168.4.1/log`.

**dsPIC30F4013**: MPLAB X + XC16 only, optimisation level 1, PICkit 4 on H1. No CLI build. `dds_tables.h` is generated by `firmware/dspic/tools/gen_tables.py`.

**dsPIC logic test on a PC** (run after any change to `dspic_firmware.c`):
```bash
cd firmware/dspic/test
clang -std=c99 -Wall -Wextra -I. -o /tmp/host_test host_test.c -lm && /tmp/host_test
```

## Architecture

```
Browser -> ESP32-S3 (AP 192.168.4.1) -> UART 9600 8N1 -> dsPIC30F4013
```

**dsPIC** (`firmware/dspic/src/dspic_firmware.c`): 10 MHz crystal x4 PLL = 10 MIPS (the limit at 3.3 V). Timer2 interrupt at 31.25 kHz runs two DDS sine oscillators into OC1/OC2 PWM and, every 4th sample, the six LED outputs. A 30.5 Hz control task in the main loop does all floating-point work: beat ramp, sequencer, colour fade, volume ramp. UART1 on RF2/RF3.

**ESP32-S3** (`firmware/esp32/src/main.cpp`): Arduino framework, built-in `WebServer`, `HTTPUpdateServer`, `ArduinoOTA`. UART1 mapped to GPIO43 (receive) and GPIO44 (transmit).

## Constraints that are easy to break

- **The UART is crossed on the PCB** (TX to TX, RX to RX). The ESP32 swaps pins in software. The dsPIC must keep its TX pin high-impedance except while replying, must never transmit unprompted, and must stay silent on unknown input, because the ESP32 boot ROM and the programming adapter share those nets.
- **Nothing may print on ESP32 UART0** (`CORE_DEBUG_LEVEL=0`, no `Serial.print`).
- **The sample interrupt has 320 instruction cycles per sample.** Keep it integer-only and short.
- **Signal level into the TPA6132A2 must stay under about 1.5 V.** The volume law in `gen_tables.py` tops out 12 dB below full scale on purpose.
- **Never enable dsPIC code protection**: removing it needs a 4.5 V bulk erase and the board runs at 3.3 V.
- GPIO0 on the ESP32-S3 is a boot strap, not an ADC input. There is no VIN sensing on this board.

## Command protocol

See `docs/uart_protocol.md`. Commands: `BEAT`, `CARRIER`, `VOL` (0-100), `AMP`, `RGB_A`, `RGB_B`, `RGB_AB`, `MODE`, `DUTY`, `SEQ`, `STATUS`, `RESET`.
